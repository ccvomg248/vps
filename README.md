## 先看懂：专线 VPS 里的“大带宽”指什么

买普通 VPS 时，带宽是个配角；买专线 VPS 时，带宽和线路才是主角。Mkcloud 官方知识库把定价逻辑拆得很直白：一条专线 VPS 的价格由计算配置、跨境路径、带宽或流量、IP 和服务成本构成，其中带宽部分分两种计法：

**共享流量款**：按“峰值带宽 + 月流量”卖。比如 200Mbps 峰值配 1TB 月流量，峰值不保证持续跑满，流量按上行、下行双向合计，用完即停，可以加购流量重置或补差价升级。

**独享带宽款**：按“固定速率 + 不限流量”卖。比如 5Mbps 独享不限流量，速率是持续保障的资源，但不限流量不等于无限速，实际吞吐仍受协议、目标服务器等影响。

这两类不能直接比数字。200Mbps 共享峰值适合短时间、突发型的任务（上传素材、店铺操作），5Mbps 独享适合要持续稳定速率的场景（长时间传输、推流基线）。哪个性价比高，取决于你的任务是突发型还是持续型。

另外有一个所有套餐通用的关键设定：每台专线 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP，你连入口操作，流量从海外出口“只出不进”。这意味着它不能当网站服务器、游戏服务端或接收外部回调的机器用，本质上是一台“出海操作机”。

这一节是全站通用的购买条件，都来自购物车页面的明确提示，比任何评测文章都重要：

1. **实名与用途限制**：需中国身份信息实名，仅限个人或企业正规用途，禁止机场、回国等违法违规用途，违者清退不退款。
2. **省级白名单**：直连款只允许一个省份的 IP 连入（下单时选省份，后续可改）。人在哪个省、宽带是哪个省，直接决定能不能用。

4. **默认无 SLA**：没有默认的可用性赔付或保障指标，需要保障要先谈定制合同。
5. **流量双向计**：计量型套餐按上行+下行合计，达到额度即停，可加购重置或升级；升降级都要走工单，降级差价不退。

## 常见问题

**200Mbps 峰值和 5Mbps 独享，到底谁快？**
看任务。峰值款 200Mbps 指上限，不保证持续跑满；独享款 5Mbps 是持续保障的速率。传大文件连续几小时的，独享款实际交付更稳；偶尔上传、日常操作的，共享峰值款的单位流量成本低得多。

**买了能建网站或开游戏服务器吗？**
不能。出口 IP 只出不进，不接收外部连入，这是产品形态决定的，不是配置问题。

**流量用超了会怎样？**
当前 IXP 款是超量停机，可自助购买流量重置或补差价升级；老套餐口径以购物车说明为准。

**开通要多久？**
官方口径约 1 分钟自动开通，系统从 Ubuntu、Debian、CentOS 到 AlmaLinux、Rocky 等常见发行版都有。

**怎么选最不亏？**
官方知识库给的方法其实最实用：先记录一个有代表性的业务周期的月流量、并发和持续上传速率，再确认自己能不能满足接入条件（省份绑定或云厂前置），最后按档位选“够用”的那档。专线 VPS 买的是匹配需求的配置和线路，不是越贵越对。
